попередження одразу. автор криворукий довбойоб. в коді є певна частина, написана ші автоматично, але переважна більшість зроблена людськими руками, і відповідальність за все однаково одна

код кривий, тож коментарів, відступів і всього подібного, що зазвичай прийнято додавати, не чекайте, їх там нема. розбирайтесь самі, це частина досвіду
що де лежить. в директорії backend один файл main.go, це весь бекенд, разом з роутами, базою, поштою і сесіями. в директорії frontend лежить фронт, src з компонентами і public з асетами, збірка стандартна через npm. в директорії rust окремий сервіс стрічки

підключається все через змінні оточення, жодних секретів в коді нема. потрібні MRIYA_DSN для postgres, MRIYA_SMTP_HOST, MRIYA_SMTP_USER і MRIYA_SMTP_PASS для листів з кодами підтвердження, MRIYA_SESSION_KEY для кук, MRIYA_AUTH_KEY_FILE для шляху до ключа. в .env.example ті самі назви з порожніми значеннями

якщо вам ці речі з поштою не потрібні у бекенді закоментуйте частину з підтвердженням пошти або автоматично після реєстрації підтверджуйте акаунт

як підняти свій форк. спочатку postgres і створена база, потім заповнений env файл. далі в backend збірка go build і запуск бінарника, він підніме http сервер. в frontend npm install і npm run build, отриманий dist віддаєш будь-яким статичним сервером і проксуєш запити на бекенд. rust сервіс збирається через cargo build і читає database.url
